Start here

The shortest path through the demo.

  1. Sign up — creates a user and returns a token.
  2. Log in — the token is remembered for every other page.
  3. User details — the first authenticated request.
  4. Turn on two-factor, then log in again to see the challenge.

How this demo is configured

Set in demo/backend/demo/settings.py — worth knowing, because it changes what the responses look like.

Token auth, not JWT. This demo pins USE_JWT = False with a TOKEN_MODEL, so logging in returns {"key": "..."} and requests carry Authorization: Token <key>. The package's own default is JWT-only — see the SPA client in demo/spa-client for that flow.
Emails go to the console. Password-reset and verification links are printed in the terminal running manage.py runserver, not sent anywhere.
